# Growth Board Examples

These examples show how Growth Ops can turn messy business information into decision-oriented GUI prototypes.

They are anonymized and self-contained HTML files. Open them locally in a browser after cloning the repository.

| Example | Language | Board Type | Purpose |
|---|---|---|---|
| [Signal Board](./growth-board-en-signal.html) | English | Signal Board | Market/theme signals into decision and action |
| [Score Board](./growth-board-ja-score.html) | Japanese | Score Board | Anonymous account/partner prioritization |
| [Scenario Board](./growth-board-zh-scenario.html) | Chinese | Scenario Board | Small-business AI modernization scenarios |

Growth Board is not a generic KPI dashboard. Each screen is built around:

```text
Signal -> Interpretation -> Decision -> Action
```
