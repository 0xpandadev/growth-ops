# PE Value Creation And Portfolio Operations

Use this file when the user asks about buying, taking over, improving, turning around, modernizing, scaling, or preparing a business for exit.

This file translates public PE value-creation patterns into practical operating logic. Do not claim proprietary access to any fund's internal playbook.

## First Principle

Value creation is not "make a better strategy deck."

It is:

```text
baseline reality -> value thesis -> prioritized levers -> owner/action/KPI -> weekly cadence -> realized cash or strategic value
```

Every value-creation output must identify:

- value lever
- baseline
- improvement action
- owner
- deadline
- KPI
- expected impact
- confidence
- dependency
- risk
- next review

## Value Creation Lifecycle

### 1. Underwrite The Value Thesis

Use before acquisition, investment, succession, or major transformation.

Ask:
- What must be true for this business to become more valuable?
- Which levers are inside management control?
- Which levers depend on market, regulation, financing, or luck?
- What operational risks should change the price, structure, or go/no-go decision?

Output:
- value thesis
- key levers
- diligence questions
- red flags
- price / structure implications when relevant

### 2. Build The Baseline

Ask:
- What is the current revenue, gross margin, EBITDA/cash, working capital, debt, churn, backlog, headcount, and capacity?
- Which metrics are trusted, stale, missing, or manually assembled?
- What is the real operating rhythm today?

Output:
- baseline scorecard
- data confidence
- missing-data list
- first dashboard fields

### 3. Identify The Lever Stack

Use the complete lever stack, but prioritize only the few that matter.

| Lever | Diagnostic question | Output field |
|---|---|---|
| Commercial growth | Where can sales, channel, segment, pricing, or conversion improve? | revenue lever, buyer, action, KPI |
| Pricing and packaging | Is price below value, complexity, or market willingness to pay? | price move, segment, risk, impact |
| Product / service focus | Which offerings create margin, retention, or strategic control? | keep / fix / stop / scale |
| Procurement / supply chain | Where can vendor terms, inventory, logistics, or indirect spend improve? | savings lever, dependency |
| Working capital | Can receivables, payables, inventory, or billing cadence release cash? | cash release, timing |
| Operations productivity | Which process creates delay, rework, waste, or bottleneck? | process fix, owner, cycle-time KPI |
| Tech / data / AI | Which workflow can be automated or made decision-ready? | workflow, data readiness, guardrail |
| Cyber / risk / controls | Which operational risk can destroy value? | risk owner, mitigation, deadline |
| Talent / org | Which role, incentive, skill, or leadership gap blocks execution? | org change, hiring/training action |
| Governance | What cadence and decision rights make execution real? | meeting rhythm, escalation rule |
| M&A / add-ons | Can scale, capability, or market access be added inorganically? | target type, integration risk |
| Exit readiness | What must be proven for a buyer/investor to pay more? | proof point, KPI history |

### 4. Prioritize Initiatives

Score initiatives by:

- value at stake
- time to cash / time to proof
- confidence
- execution complexity
- dependency
- downside risk
- owner capacity

Default scoring:

```text
Priority = impact x confidence x urgency / complexity
```

Do not overfit the formula. Use it to force explicit tradeoffs.

### 5. Run The 100-Day Value Plan

For an acquired, inherited, or newly managed business:

```text
Day 0-10: cash, data, people, customers, must-not-break operations
Day 11-30: baseline scorecard, stop-loss actions, quick wins, owner map
Day 31-60: commercial/pricing/operations initiatives with owners and KPIs
Day 61-100: governance cadence, system fixes, talent gaps, value tracking
```

Always include:

- what to protect
- what to stop
- what to fix first
- what not to automate yet
- what needs professional support

### 6. Track Realized Value

Use transformation-office discipline:

- one source of truth
- initiative owner
- finance validation
- weekly action review
- stage gates from idea to implemented to realized
- blocker escalation
- benefits tracking

Output fields:
- initiative
- baseline
- target
- realized-to-date
- stage
- blocker
- next action
- owner
- review date

## Public Method Translations

### KKR Capstone Pattern

Essence:
- value creation starts during diligence, becomes a concrete plan, then is implemented on the ground.
- broad lever set: organic growth, business expansion, digital/technology, procurement, governance, M&A, operational scalability, human capital, sustainability, risk.

Use when:
- the case needs a full operating improvement plan.

Output effect:
- add diligence levers, value plan, owner table, and cross-functional lever stack.

### Vista Pattern

Essence:
- software value creation comes from disciplined operating excellence, repeatable best practices, AI capacity, talent, board/governance, and ecosystem learning.

Use when:
- software, SaaS, enterprise tools, or AI-enabled operations are involved.

Output effect:
- add software operating metrics, GTM/product/CS/process discipline, AI readiness, talent bench, and board-level governance.

### Thoma Bravo Pattern

Essence:
- sector specialization in software plus operational expertise can improve performance after acquisition.

Use when:
- evaluating mature software businesses, profitability improvement, pricing/packaging, add-ons, or operational tightening.

Output effect:
- add software profitability, retention, product focus, pricing, support efficiency, and add-on integration checks.

### CD&R Pattern

Essence:
- partnership orientation, operating partners, industry insight, and management collaboration matter.

Use when:
- founder/family/legacy/owner-led businesses require improvement without destroying trust.

Output effect:
- add stakeholder alignment, operating partner role, owner transition, management partnership, and industry-specific playbook.

### EQT Motherbrain Pattern

Essence:
- AI and data augment human investment judgment across sourcing, diligence, and value creation; data alone is not enough.

Use when:
- the task involves market radar, target discovery, investment screening, or AI-assisted operating improvement.

Output effect:
- add entity dataset, signal scoring, human review, monitoring cadence, and data-to-action loop.

### Apollo APPS Pattern

Essence:
- generalist operating partners plus deep functional expertise support transformational growth.

Use when:
- the case needs cross-functional operating support rather than one narrow fix.

Output effect:
- add generalist owner, specialist lanes, transformation opportunities, and functional workstreams.

### Bain PE Value Creation Pattern

Essence:
- align management and investors, assure/amplify/accelerate delivery, and create value from strategy through execution.

Use when:
- the user needs a value-creation plan that connects thesis, governance, and measurable delivery.

Output effect:
- add investor/management alignment, delivery assurance, value tracking, and workstream governance.

- PE-style operating plan
- turnaround plus growth
- "make this business better"

## Anti-Patterns

- Calling something "PE-style" with no baseline, owner, KPI, or cash impact.
- Optimizing EBITDA while damaging customer trust or core operations.
- Assuming a small business can absorb enterprise-grade transformation.
- Building AI before process, data, ownership, and controls are clear.
- Treating a 100-day plan as a wishlist instead of a weekly operating cadence.
