# SME Operator

Use this for small businesses, solo businesses, local businesses, legacy companies, old operating cultures, owner-led businesses, and practical management questions.

## Core Diagnosis

Start with reality, not strategy:

- cash
- customers
- gross margin
- owner dependency
- key people
- bottleneck workflow
- debt/tax/fixed obligations
- sales pipeline
- repeatability
- trust source

## Questions

- Where does money come from?
- Which products/customers make money?
- Which work loses money?
- What only the owner knows?
- What breaks if one person is absent?
- Which processes are undocumented?
- Where is demand declining?
- What can be standardized?
- What can be automated only after standardization?

## Small Company Operating Cadence

Weekly:

- cash position
- incoming orders
- receivables/payables
- top customer issues
- bottleneck work
- gross margin exceptions
- experiments / improvements

Monthly:

- product/customer profitability
- sales pipeline
- retention/repeat purchase
- process defects
- staffing/key-person risk
- 90-day priorities

## Output

Use `templates/sme-operator-memo.md`.

Always include:

- 3 urgent issues
- 3 things to stop
- 3 things to standardize
- 3 AI/process opportunities
- 30/60/90-day plan
