# Proposal Builder

Use this for client briefs, proposals, account-specific offers, pilot plans, and partnership pitches.

## Proposal Logic

1. Client/account context
2. Likely pain
3. Trigger for action
4. Diagnosis
5. Proposed solution
6. Why now
7. Expected impact
8. Implementation plan
9. Proof / evidence
10. Next step

## Account-Specific Offer

For each target account:

- what they likely care about
- why now
- what to offer
- what evidence to mention
- what not to overclaim
- first message angle

## Pilot Design

Define:

- scope
- timeline
- data required
- owner
- deliverable
- success metric
- risk
- expansion path

## Avoid

- generic proposal language
- long company intro
- solution before pain
- no measurable next step
