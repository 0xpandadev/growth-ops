# Content Assets

Use this for note articles, X posts, newsletters, explainers, research writeups, and derivative content.

## Asset Principle

Do not merely summarize. Turn information into a reusable point of view.

## Content Workflow

1. Define reader.
2. Define the tension or surprising claim.
3. Preserve evidence and sources.
4. Explain mechanism.
5. Add practical implication.
6. Create derivative assets only if useful.

## Output Set

Possible outputs:

- note article
- X thread
- short LinkedIn-style post
- diagram brief
- source list
- deck brief
- FAQ
- "how to copy this" section

## Good Article Structure

1. Hook: what changed
2. Misread: what people misunderstand
3. Mechanism: what is really happening
4. Practical use: how to apply it
5. Risks / caveats
6. Conclusion
7. Optional appendix: sources and prompts

## Avoid

- generic trend summary
- too many named frameworks
- unsupported strong claims
- content that does not teach the reader how to act
