# Evidence Rules

## Labels

Use labels when claims matter:

- `Fact`: directly supported by source or user-provided data.
- `Inference`: reasoned from facts, not directly proven.
- `Assumption`: necessary premise.
- `Unknown`: not verified.
- `Signal`: weak evidence worth tracking.
- `Contradiction`: evidence that challenges the thesis.

## Source Handling

Prefer:

- primary sources
- official docs
- filings
- government data
- company pages
- product docs
- direct customer or user evidence

Use secondary sources for context, market maps, and pattern recognition, but do not treat them as ground truth.

## Citation Discipline

For important claims, include:

- source title or organization
- URL or document
- date if available
- page, slide, section, or table when available

If no source is available, label the claim as `Inference`, `Assumption`, or `Not verified`.

## Private Data

Never send private user files, credentials, emails, local paths, or workspace data to external services unless the user explicitly asks and approval is appropriate.
