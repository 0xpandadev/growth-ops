# Growth Board HTML Brief

## Goal

Create a Growth Board HTML prototype that turns analysis into a decision surface, not a generic dashboard.

## Board Type

- Primary board:
- Supporting modules:
- Reason:

## Required Screen Sections

1. Header
   - title
   - decision statement
   - confidence / status

2. Signal Inbox
   - strongest signals
   - source chips
   - confidence tags
   - missing evidence

3. Decision Map
   - how signals affect the decision
   - selected option
   - rejected alternatives
   - falsifier

4. Main Board Module
   - Score Board / Map Board / Scenario Board / Action Board content

5. Action Rail
   - next action
   - owner / condition
   - timing
   - follow-up question

6. Evidence Drawer
   - facts
   - assumptions
   - unknowns
   - source list

## Visual Direction

- High-end operating console.
- Calm base, one sharp accent, thin dividers, dense information.
- Meaningful icons only.
- No decorative-only charts, flowers, blobs, stock-style filler, or empty KPI-card dashboard.
- Text must not overflow.
- Mobile layout should stack: header, action rail, signals, decision map, details.

## Interaction Ideas

- Filter signals by confidence.
- Toggle facts / assumptions / unknowns.
- Expand evidence drawer.
- Compare scenario assumptions.
- Mark action as next / later / blocked.

## QA Checklist

- Does the screen show Signal -> Interpretation -> Decision -> Action?
- Does every visual encode meaning?
- Is the recommended action obvious?
- Are unknowns and falsifiers visible?
- Are sources visible but not noisy?
- Does it avoid generic dashboard appearance?
- Does it work on mobile and desktop?
